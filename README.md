# EduNew — Unofficial EduPage for Android

Fast, modern, and simple Android app to view your EduPage timetable and substitutions after login. Filter by classes, groups, and special subjects to see exactly what matters.

[![Kotlin](https://img.shields.io/badge/Language-Kotlin-7F52FF?logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Android](https://img.shields.io/badge/Platform-Android-3DDC84?logo=android&logoColor=white)](https://developer.android.com/)

## Features
- Secure login with your EduPage account
- Clean timetable overview
- Clear substitutions view
- Powerful filters: class, group, special subject
- Built with Kotlin and modern Android practices

## Install
- Preferred: download the latest APK from [Releases](../../releases) and install on your device.
- Or build from source (below).

## Build from source
1. Clone: `git clone https://github.com/ProfessorQuantumUniverse/EduNew9.git`
2. Open in Android Studio
3. Let Gradle sync
4. Run on a device or emulator

## Usage
1. Log in with your EduPage credentials
2. Browse timetable and substitutions
3. Apply filters (class, group, special subject) anytime
